# Private test corpus

PDFs here are used by `npm run test:edit-stability` (every editable line of every file is checked) and
never leave this machine: everything in this folder except this README is gitignored.

Put real-world files here — Word/Google Docs/LibreOffice/LaTeX/Canva exports, forms, scans. Real Word
output can be generated with `npm run corpus:word` (Windows with Microsoft Word installed).
